# usage-mods

Claude Code 입력창 위에 지금 작업 상태와 사용량을 보여주는 모드입니다.

```
● 작업 중 · 1분 23초 · 도구 7회
지금 (15초째): 명령 실행 — Run tests
컨텍스트 ███░░░░░░░  [ 압축 ]  5시간 ██░░░░░░░░  7일 █░░░░░░░░░ 초기화까지 3일 0시간
```

### 작업 상태 (위 줄들)

| 상태 | 보이는 모습 |
| --- | --- |
| 작업 중 | `● 작업 중 · 1분 23초 · 도구 7회` / `지금 (15초째): 명령 실행 — Run tests`. 점(●○)이 1초마다 바뀌면 일하는 중입니다. 도구를 쓰지 않을 때는 `생각하거나 답을 쓰는 중…`이라고 나옵니다. 뒤에서 도는 작업이나 예약이 있으면 흐린 셋째 줄이 붙습니다: `◌ 백그라운드 (3분째): 명령 실행 — Run dev server`, `◌ 백그라운드: 명령 2개 · 모니터 1개 · 예약 1개 (3분 후)`. |
| 나를 기다림 | `! 나를 기다리는 중 · 5초째` / `질문에 답해 주세요`, `계획을 확인해 주세요`. 노란색이고 점이 멈춥니다. 시간은 기다리기 시작한 때부터 잽니다. |
| 승인 요청 | `! 승인 요청이 떴어요 · 3초 전` / `명령 실행 — npm install · 승인했다면 실행 중이에요`. 도우미(서브에이전트)가 띄운 승인 요청도 `! 도우미가 승인 요청을 띄웠어요`로 보여 줍니다. |
| 끝남 | `✓ 끝났어요 · 2분 5초 걸림 · 도구 12회 · 다음 지시를 기다려요` |
| 중단·오류 | `■ 중단했어요 · …`, `✕ 오류로 멈췄어요 · 대화에 뜬 안내를 확인해 주세요`, `✕ 요청을 거절했어요 · 다르게 말해 보세요` |
| 백그라운드 남음 | 본 작업이 끝나도 뒤에서 도는 것이 있으면 한 줄이 붙습니다. 명령·모니터·워크플로 하나면 `◌ 백그라운드 (12분째): 명령 실행 — Run dev server`, 여럿이면 `◌ 백그라운드에서 아직 일하는 중 · 명령 2개 · 모니터 1개`입니다. 도우미(서브에이전트)가 함께 일하면 `● 백그라운드에서 아직 일하는 중 · 도우미 1명 · 명령 2개`, 도우미만 남았으면 `○ 백그라운드 도우미 2명은 아직 일하는 중`입니다. |
| 예약 | `/loop`, 예약 만들기(CronCreate), 다음 실행 예약(ScheduleWakeup)이 걸려 있으면 `◷ 4분 후 실행 · 배포 상태 확인`, 여럿이면 `◷ 예약 3개 · 다음은 곧 실행`이 붙습니다. |
| 알림·예약으로 시작 | 백그라운드 작업이 끝났다는 알림으로 Claude가 일을 시작하면 `● 알림 받고 작업 중 · …`, 예약한 시각이 되어 시작하면 `● 예약 작업 중 · …`입니다. 예약으로 시작한 작업은 오래 걸려도 끝났다고 알리지 않습니다. |

- 이 대화에서 아직 아무 작업도 하지 않았을 때는 사용량 줄만 보입니다. 작업 도중에 모드를 처음 켜면 그 작업 동안은 `작업 중…`만 보이고, 다음 작업부터 자세히 보입니다.
- 승인 요청이 뜬 순간은 알 수 있지만 승인을 누른 순간은 알 수 없습니다. 그래서 30초가 지나면 노란 줄을 거두고 `지금 (37초째, 승인 요청이 떴었어요): …`라고 흐리게 보여 줍니다.
- 30초 넘게 걸린 작업이 끝나면 알려 줍니다. iTerm2·kitty·Ghostty에서는 터미널 알림으로, 그 밖의 터미널(Windows 터미널 포함)과 데스크톱 앱에서는 오른쪽 위에 10초 동안 작은 알림 상자로 보여 줍니다. 자리를 비웠다 돌아왔을 때는 띠의 `✓ 끝났어요` 줄을 보면 됩니다.
- `◌`와 `◷` 줄은 깜빡이지 않습니다. Claude가 일하는 것이 아니라, 명령이 돌거나 예약이 기다리고 있다는 뜻이기 때문입니다.
- 백그라운드 작업이 끝난 것은 끝남 알림이 오거나, Claude가 답을 마칠 때 받는 '아직 도는 작업' 목록에서 빠졌을 때 압니다. 그래서 알림 없이 끝난 작업은 다음 답변이 끝날 때까지 남아 보일 수 있습니다.
- 반복 예약은 한 번 돈 뒤에는 다음 실행 시각을 알 수 없어서 `◷ 반복 예약 · …`처럼 시각 없이 보입니다.
- `/clear`를 하면 백그라운드·예약 줄이 비었다가, 다음 답변이 끝날 때 아직 남은 것이 다시 채워집니다.

### 사용량 (아래 줄)

- 컨텍스트, 5시간, 7일 사용률을 막대로 표시합니다. 데스크톱 앱에서는 둥근 막대, 터미널에서는 10칸 글자 막대입니다. 마우스를 올리면 퍼센트가 보이고, 5시간·7일 막대에서는 `23% · 2시간 13분 후 초기화`처럼 초기화까지 남은 시간도 함께 보입니다. 데스크톱 앱에서는 막대 위에 뜨는 카드에 글자로, 터미널에서는 막대 자리에 반전 글자로 보입니다.
- 80% 미만은 초록, 80% 이상은 노랑, 90% 이상은 빨강입니다. 글자 색은 쓰는 테마의 성공·경고·오류 색을 따릅니다.
- `[ 압축 ]` 버튼은 답변이 끝났고 컨텍스트에 내용이 있을 때만 켜집니다. 꺼져 있을 때는 흐리게 보이고, 누르면 왜 안 되는지 알려 줍니다. 켜졌을 때 누르면 "압축하시겠습니까? 예 / 아니오"를 묻고, 예를 고르면 `/compact`와 같이 압축합니다.
- 7일 막대 바로 옆에 주간 한도가 초기화되기까지 남은 시간을 보여줍니다. 하루 미만이면 `22시간 47분`, 한 시간 미만이면 `13분`으로 바뀌고 1분마다 갱신됩니다.
- 5시간/7일 사용률과 초기화 카운트다운은 구독 계정에서만 표시됩니다.
- API 키로 쓸 때는 맨 끝에 이 대화의 비용(`$0.50`)을 보여 줍니다. 구독 계정에서는 실제로 청구되는 돈이 아니라서 보이지 않습니다.

## 설치

터미널에서 Claude Code를 열고 입력합니다.

```
/plugin install usage-mods --marketplace akixi-maison/usage-mods
```

`Add marketplace?`에 `y`, 설치 범위는 **User**를 고르면 모든 프로젝트에 적용됩니다.
